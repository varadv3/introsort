# Description
- An example of mix sort, where more than 1 sorting algorithm is used to increase the efficiency.

# Setup
- Clone the repo.
- Run `make all`.
- Execute the binary which will be created in build folder.
- Use env var `LD_LIBRARY_PATH=build` while running the executable.
